# Known deviations from the transitional schemas in files hanji did not write, each with the
# reason it is accepted. Kit exports of these files carry the same deviations (GetPut keeps what
# it does not edit), so each file glob also matches the kit's file names (NN-…-slug-variant.ext).
# Globs match the file's base name, case-insensitively.
#
# file-glob | part-glob | message-regex | reason

# docx
*korean-report*.docx | word/document.xml | pStyle': This element is not expected | LibreOffice 24.2 (make_korean.sh) writes w:sectPr first in a paragraph's w:pPr; Word opens the file and its kit exports without repair (kit v8)
*korean-report*.docx | word/numbering.xml | numFmt': This element is not expected | LibreOffice 24.2 writes w:pStyle before w:numFmt in w:lvl; Word opens the file and its kit exports without repair (kit v8)
*.docx | customXml/item*.xml | bibliography\}Sources', attribute 'Version' | Word writes a Version attribute on the bibliography's b:Sources, which the schema does not declare; Word reads it back
*.docx | word/*.xml | \{urn:schemas-microsoft-com:vml\}\w+', attribute '(\{urn:schemas-microsoft-com:office:office\}gfxdata|ID)' | VML is legacy markup kept for compatibility, and its schemas lack attributes Word writes (o:gfxdata, ID); Word reads them
